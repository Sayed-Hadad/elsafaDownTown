# Safa Downtown Halls Booking System

نظام إدارة حجوزات Safa Downtown Halls - Safa Downtown Halls Booking Management System

## المميزات الرئيسية

✓ نظام حجوزات قاعات كامل
✓ دعم اللغة العربية كاملاً مع واجهة RTL
✓ نظام تحكم إداري متقدم
✓ إدارة الموظفين والأدوار
✓ تقويم ديناميكي بدون تحديث يدوي
✓ نظام توفر الأوقات والفترات الزمنية
✓ سجل أنشطة وتتبع شامل
✓ تصدير البيانات إلى CSV
✓ واجهة مستخدم حديثة وسريعة

## المتطلبات

- Python 3.8+
- Flask 3.0.0
- SQLAlchemy 3.1.1
- SQLite3

## التثبيت والتشغيل

### 1. تثبيت المكتبات
```bash
pip install -r requirements.txt
```

### 2. تشغيل التطبيق
```bash
python run.py
```

سيتم فتح التطبيق على: http://localhost:5000

### 3. بيانات المستخدم التجريبية

بعد التشغيل للمرة الأولى، ستُضاف بيانات تجريبية تلقائياً:

**حساب مدير:**
- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

**حسابات موظفين:**
- staff1 / staff123
- staff2 / staff123

## الأدوار والأذونات

### دور المدير (Admin)
- عرض جميع الحجوزات
- تصريح أو رفض الحجوزات
- إدارة القاعات (إضافة، تعديل، حذف)
- إدارة الموظفين (إضافة، تعديل، حذف)
- عرض سجلات الأنشطة
- عرض التقويم الكامل
- عرض الإحصائيات

### دور الموظف (Staff)
- إضافة حجوزات جديدة
- عرض حجوزاتهم
- تعديل حجوزاتهم
- عرض القاعات المتاحة
- عرض لوحة التحكم الخاصة بهم

## الميزات الرئيسية

### 1. نظام التقويم الديناميكي
- يُحدّث نفسه تلقائياً بناءً على تاريخ النظام
- لا يتطلب أي تحديث يدوي
- يدعم السنوات الكبيسة والأشهر المختلفة
- يعطل الأيام والأشهر والسنوات الماضية

### 2. نظام التوفر والفترات الزمنية
- حساب الفترات المتاحة والمشغولة تلقائياً
- منع التعارضات في الحجوزات
- اقتراح أوقات بديلة عند وجود تضارب
- واجهة سهلة الاستخدام

### 3. إدارة الحجوزات
- إضافة حجوزات جديدة
- تعديل الحجوزات الموجودة
- حذف الحجوزات
- تصفية البحث المتقدم
- تصدير إلى CSV

### 4. سجلات الأنشطة
- تتبع جميع الإجراءات
- تسجيل تسجيلات الدخول والخروج
- تسجيل إنشاء وتعديل الحجوزات
- تسجيل إدارة القاعات والموظفين

## نماذج قاعدة البيانات

### جدول المستخدمين (users)
- معرف فريد
- اسم المستخدم
- كلمة المرور المشفرة
- الدور (admin/staff)
- تاريخ الإنشاء

### جدول القاعات (halls)
- معرف فريد
- اسم القاعة
- الوصف
- السعة
- السعر
- أوقات التشغيل
- الحالة (نشطة/معطلة)

### جدول الحجوزات (bookings)
- معرف فريد
- معرف القاعة
- اسم العميل
- رقم الموبايل
- التاريخ والوقت
- الأسعار والعربون
- الحالة
- الملاحظات

### جدول السجلات (staff_logs)
- معرف فريد
- معرف المستخدم
- نوع الإجراء
- التفاصيل
- الوقت والتاريخ

## الواجهات البرمجية (APIs)

### `/api/calendar?month=YYYY-MM`
الحصول على أيام الشهر ديناميكياً

### `/api/availability?hall_id=X&date=YYYY-MM-DD`
الحصول على الفترات الزمنية المتاحة لقاعة معينة

## التخصيص والتوسع

يمكنك تخصيص التطبيق بسهولة:

1. **تغيير الألوان والتصاميم**: عدّل `style.css`
2. **إضافة مميزات جديدة**: أنشئ blueprints جديدة في `routes/`
3. **تغيير الرسائل**: عدّل الرسائل في `views.html`
4. **إضافة حقول جديدة**: عدّل `models.py`

## المشاكل الشائعة والحلول

### خطأ: "Module not found"
تأكد من تثبيت جميع المكتبات:
```bash
pip install -r requirements.txt
```

### خطأ: "Database is locked"
احذف ملف قاعدة البيانات وابدأ من جديد:
```bash
rm elsafa_halls.db
python run.py
```

### الواجهة غير قابلة للاستخدام على الموبايل
تأكد من أن `base.html` يحتوي على `meta viewport` (موجود بالفعل)
